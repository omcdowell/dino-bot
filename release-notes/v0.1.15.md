### New
- DinoBot runs bots and workers on pi and Claude Code only. The other coding agents (Codex, OpenCode, OMP, the ACP agents and the Claude Agent SDK agent) and `dinobot claude-code install` are gone.
- Claude Code bots show a running command's output as it runs, take `/skill:<name>` and `/compact`, and have the session list, rewind and the `/optchat` profile tools, as pi bots do.
- A new Claude Code chat opens with the bot's history.

### Fixed
- The bots page no longer reloads itself and downloads every avatar again when DinoBot's bots plugin reloads.
- Images you send to a pi bot stay in the chat after the bot switches engine.
- New chat follows a bot's engine switch, and a bot's model list is rebuilt when its engine or proxy changes.
- The pairing code carries one address, the tailnet IP. With both the name and the IP, the app switched between them under load. An app built from this release (desktop or iPhone) drops the saved name by itself; you don't need to pair again.
- Connections from your phone and desktop stay end-to-end encrypted, and DinoBot still refuses unencrypted ones, as before: nothing to do.
