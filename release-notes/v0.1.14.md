### New
- Claude Code bots now work like pi bots: the answer streams as it is written, a turn that ends on an API error or a refusal says why, a prompt waiting in the bot's terminal shows as a permission card, and stopped or failed turns are kept in memory.
- A reopened Claude Code chat shows its tool calls and the images you sent; images a tool returns show in the chat.
- A model or effort switch on a Claude Code bot applies from its next step, with no restart.
- Messages you send while your computer is not connected yet wait in the chat and go when it reconnects.

### Fixed
- Bot avatars load faster in the chat header, and designed avatars are centred.
- Pairing by QR code uses a one-use ticket only; the password is no longer in the QR code.
