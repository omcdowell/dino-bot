# Supported providers

For the concept and how Paseo manages providers, see [Providers](/docs/providers). To add or configure your own, see [Custom providers](/docs/custom-providers).

## Native support

Works out of the box once the underlying CLI is installed and authenticated.

- [Pi](https://pi.dev). Minimal terminal-based coding agent with multi-provider LLM support.

Claude Code runs in the Paseo terminal (see [Claude Code](/docs/claude-code)). Other agents can be
added as [provider plugins](/docs/plugins/providers).
